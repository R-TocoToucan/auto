## D1 — the RIGHT fix: reduced dataset + single `run_backtest` call

The `price_over_sma` strategy's `generate_signals` maintains a `current_state: TargetState = _INITIAL_STATE` variable inside its loop over `candles` (`src/bithumb_bot/strategy/baseline.py` lines 182 + 214-228). Every transition mutates that variable; every emitted signal is a diff against it. So calling `generate_signals(warmup + forward, config)` and then trying to re-derive a "forward-only" transition stream is intrinsically fragile: the raw signal at candle 1199 (last warmup) has already committed the strategy to LONG or CASH from the strategy's perspective. Any downstream re-derivation that pretends the forward window starts fresh will disagree with what the strategy would have said had it started fresh.

**The reduced-dataset trick** avoids this without touching the strategy or the shared engine:

- The SMA needs `lookback_candles` closes to be defined. Given `WARMUP_CANDLE_COUNT = 1200` (in the runner) and `config.strategy.lookback_candles = 1200` (in production), we need EXACTLY 1200 closes to compute the first valid SMA. Those 1200 closes should END at `paper_start_ts_utc` — i.e., the last `lookback` closes preceding-inclusive of `paper_start_ts_utc`.
- Construct `reduced_candles = dataset.candles[WARMUP_CANDLE_COUNT - (lookback - 1) : ]` (= `dataset.candles[1:]` when both are 1200).
- Build a reduced `CandleDataset` via `dataset.model_copy(update={"candles": reduced_candles, "missing_intervals_utc": kept_missing})`.
- Call `run_backtest(reduced_dataset, snapshot, config)` EXACTLY ONCE.
- In `run_backtest`'s loop, `generate_signals` sees the reduced series and — because it uses the standard "warm-up: need at least `lookback` candles ending at index i" gate — emits nothing for reduced indices `[0..lookback-2]` (which map to original indices `[1..WARMUP_CANDLE_COUNT-1]`). At reduced index `lookback - 1` (which IS the first forward candle at `paper_start_ts_utc`), the strategy's `current_state` is still CASH (initial), and the transition check runs cleanly against the freshly-computed SMA over the last `lookback` closes.
- All accounting (fees, slippage, tick/step, min-order, notional cap, protective stop, stopped-out lockout) stays inside `run_backtest`'s call to `execute_intent` / `evaluate_protective_stop` — same UNMODIFIED primitives, same event order.

**Worked example from the task brief:**

- Original dataset: 1199 warmup at close=100000000 + 1 warmup at close=101000000 + 1 forward at close=100500000 (WARMUP_CANDLE_COUNT + 1 = 1201 candles total). Lookback = 1200.
- Reduced: `dataset.candles[1:]` = last 1199 warmup ([100M]*1198 + [101M]) + [100.5M forward] = 1200 candles.
- At reduced index 1199 (= first forward = paper_start), running_sum = 100_000_000 * 1198 + 101_000_000 + 100_500_000 = 120_001_500_000; SMA = 120_001_500_000 / 1200 = 100_001_250 exact.
- Upper hysteresis band = SMA * (10000 + 75) / 10000 = 100_001_250 * 10075 / 10000 = 100_751_259.375 exact.
- close 100_500_000 < 100_751_259.375 → strategy stays CASH → NO signal at reduced index 1199.
- No pending intent, no fills. Return: `forward_entries=()`, `final_cash_krw=starting_cash_krw`, `final_position_qty=0`.

## D1 result-shape mapping (how `run_backtest`'s output becomes `PaperSessionResult`)

- `run_backtest(reduced_dataset, snapshot, config)` returns a `BacktestResult` whose `entries` cover the reduced-dataset's ledger — because generate_signals emits nothing before reduced index `lookback - 1`, and no BUY intent can be created without a LONG signal, `entries` is effectively (and always) the forward-window ledger.
- Belt-and-suspenders filter: assign `forward_entries = tuple(e for e in br.entries if e.source_open_time_utc >= paper_start_ts_utc)` — semantically equivalent, defensive against any future change in the strategy's warmup rules.
- `PaperSessionResult.backtest_result` is the returned `BacktestResult` as-is (no synthesis needed anymore — the erv-era synthesis existed only because the fresh-portfolio forward loop didn't return a real `BacktestResult`). This aligns `paper_run.py`'s existing handler code that reads `session.backtest_result.final_cash_krw`, etc.
- `forward_signal_count = br.signals_generated` (the count of signals emitted over the reduced series; equals the number of forward transitions, since no signals fire before reduced index `lookback - 1`).

## D2 — tightened resume-time immutable-prefix verification

Extend `_verify_processed_prefix_fingerprints(state_dir, dataset, prior_state)` to enforce, IN THIS ORDER, all five checks, each raising `ProcessedPrefixMutatedError` on failure BEFORE any file mutation. Every message is fixed-length, names the offending value(s), and never splices in dataset bytes.

1. **Missing file:** `if prior_state.forward_candle_count > 0 and not (state_dir / "candle_fingerprints.jsonl").is_file(): raise ProcessedPrefixMutatedError("candle_fingerprints.jsonl is missing at {path!s} but prior state.json reports forward_candle_count={n} — audit trail incomplete")`.
2. **Malformed rows:** parse each line by hand (do NOT reuse `read_jsonl` which raises `ValueError`); on any `json.JSONDecodeError`, missing `"open_time_utc"` key, missing `"sha256"` key, or `"sha256"` not being a 64-char lowercase hex string, raise `ProcessedPrefixMutatedError(f"candle_fingerprints.jsonl line {i+1} is malformed: {reason}")`.
3. **Row count:** `if len(recorded) != prior_state.forward_candle_count: raise ProcessedPrefixMutatedError(f"candle_fingerprints.jsonl has {len(recorded)} rows but state.json reports forward_candle_count={prior_state.forward_candle_count} — audit trail truncated, duplicated, or extended")`.
4. **Order + missing-in-current + content:** for `i in range(len(recorded))`:
   - `expected_idx = WARMUP_CANDLE_COUNT + i` — refuse if `expected_idx >= len(dataset.candles)` (the current dataset is shorter than the prior processed prefix).
   - `expected_open_time = dataset.candles[expected_idx].open_time_utc`
   - `recorded_open_time = _parse_missing_utc(recorded[i]["open_time_utc"])`
   - `if recorded_open_time != expected_open_time: raise ProcessedPrefixMutatedError(f"candle_fingerprints.jsonl row {i} open_time_utc={recorded_open_time.isoformat()} != current dataset candle[{expected_idx}].open_time_utc={expected_open_time.isoformat()} — audit trail reordered or dataset diverged")`
   - `if candle_fingerprint(dataset.candles[expected_idx]) != recorded[i]["sha256"]: raise ProcessedPrefixMutatedError(f"candle at {expected_open_time.isoformat()} has mutated (SHA-256 mismatch) — refusing to append onto a candle prefix whose content changed")`
5. **Tail:** if `recorded` is non-empty, `if recorded[-1]["open_time_utc"] != prior_state.last_processed_open_utc: raise ProcessedPrefixMutatedError(f"candle_fingerprints.jsonl last row open_time_utc={recorded[-1]['open_time_utc']} != state.json last_processed_open_utc={prior_state.last_processed_open_utc} — tail divergence")`.

Check #4's per-row order+content pair supersedes the existing dict-lookup form (`current_by_open_time = {c.open_time_utc: c for c in dataset.candles}`); the position-parallel form catches reordering that the dict form would silently accept.

**`ProcessedPrefixMutatedError` docstring:** BROADEN to enumerate all five modes. Do NOT rename the class and do NOT introduce a sibling `ProcessedPrefixCorruptedError`. Justification: (a) same operational contract (fail-closed refusal, don't touch the audit trail); (b) same recovery path (operator inspects the state-dir, decides whether to delete-and-restart or repair); (c) the CLI already catches this class in its except-tuple — a sibling class would fragment the tuple for zero operational benefit; (d) the message is what a human reads to distinguish modes, and each mode's message is precise. Update the docstring in `src/bithumb_bot/errors.py` to list mutation / missing-in-current-dataset / row-count-mismatch / order-mismatch / tail-mismatch / malformed-row / missing-file as the exhaustive set.

## D3 — upfront dataset/config mismatch rejection

Add a new exception class in `src/bithumb_bot/errors.py`:

```
class PaperInputContractMismatchError(BithumbBotError):
    """Raised BEFORE any state mutation when the dataset's declared
    market or unit_minutes disagrees with config.strategy.market or
    config.strategy.unit_minutes.

    Mirrors the semantics of `run_backtest`'s upfront ValueError on
    the same mismatch (see `bithumb_bot/backtest/runner.py` pre-flight),
    but with a dedicated class so the CLI can format a clean refusal
    without catching bare ValueError. The paper runner enforces this
    upfront (before state_dir.mkdir) rather than deferring to
    `run_backtest` because the runner performs its own state-file
    writes and must refuse before mutating anything.

    Message names the mismatched field and both sides' observed values;
    no dataset bytes are spliced into the exception surface.
    """
```

Add to `__all__` in `errors.py` (alphabetical position: between `NotionalCapExceededError` and `ObsoleteVerificationBundleError`).

Position of the check in `run_paper_session`: as the VERY FIRST check, BEFORE `state_dir` mkdir. `mkdir` itself is a benign filesystem mutation (creates an empty directory) but the fail-closed discipline is clearer when D3 rejects before touching the filesystem at all.

```
            f"config.strategy.unit_minutes={config.strategy.unit_minutes}"
        )

    # -------- 1. state_dir sanity + mkdir --------
    if state_dir.exists() and not state_dir.is_dir():
        raise PaperStateDirError(...)
    state_dir.mkdir(parents=True, exist_ok=True)

    # -------- 2. Dataset length check --------
    if len(dataset.candles) < WARMUP_CANDLE_COUNT + 1:
        return _refused(... code="InsufficientForwardCandlesError" ...)

    # -------- 3. Reduced-dataset feasibility --------
    lookback = config.strategy.lookback_candles
    pre_needed = lookback - 1
    reduce_start_idx = WARMUP_CANDLE_COUNT - pre_needed
    if reduce_start_idx < 0:
        return _refused(
            ...,
            reason=(f"config.strategy.lookback_candles={lookback} requires "
                    f"{pre_needed} pre-paper candles but WARMUP_CANDLE_COUNT="
                    f"{WARMUP_CANDLE_COUNT} only provides "
                    f"{WARMUP_CANDLE_COUNT} — increase warmup or reduce lookback"),
            code="InsufficientPaperLookbackError",
        )

    # -------- 4. Incomplete-candle refusal (paper-specific) --------
    paper_start_ts_utc = dataset.candles[WARMUP_CANDLE_COUNT].open_time_utc
    forward_candle_count = len(dataset.candles) - WARMUP_CANDLE_COUNT
    step = timedelta(minutes=dataset.unit_minutes)
    for candle in dataset.candles:
        if candle.open_time_utc + step > now_utc:
            return _refused(..., code="IncompleteCandleError")

    # -------- 5. Divergence hashes --------
    hashes = _compute_divergence_hashes(dataset, config, snapshot)

    # -------- 6. Load prior state + D2 verification (all fail-closed BEFORE any write) --------
    resume_ctx = _load_resume_context(state_dir, dataset, hashes, paper_start_ts_utc)
    # inside _load_resume_context:
    #   6a. load_state(state_dir) -> may return None
    #   6b. _resume_divergence_check(...) -> raises ForwardDatasetDivergenceError
    #   6c. _verify_processed_prefix_fingerprints(...) -> raises ProcessedPrefixMutatedError
    #       (D2 tightened: missing-file, malformed, row-count, order+content, tail)

    # -------- 7. Build reduced dataset --------
    reduced_candles = dataset.candles[reduce_start_idx:]
    kept_missing = [s for s in dataset.missing_intervals_utc
                    if _parse_missing_utc(s) >= reduced_candles[0].open_time_utc]
    reduced_dataset = dataset.model_copy(update={
        "candles": reduced_candles,
        "missing_intervals_utc": kept_missing,
    })

    # -------- 8. Call the UNMODIFIED run_backtest exactly once --------
    br = run_backtest(reduced_dataset, snapshot, config)

    # -------- 9. Refusal short-circuit (NO state write on invalid) --------
    if br.invalid_reason is not None:
        return PaperSessionResult(...backtest_result=br, invalid_reason=..., ...)

    # -------- 10. Defensive filter to forward-only ledger --------
    forward_entries = tuple(e for e in br.entries
                            if e.source_open_time_utc >= paper_start_ts_utc)

    # -------- 11. Fills / signals prefix-replay check (existing) --------
    fills_path = state_dir / "fills.jsonl"
    on_disk_fills = read_jsonl(fills_path)
    recomputed_prior_fills = [_serialize_ledger_entry(e)
                              for e in forward_entries[:prior_fill_count]]
    _assert_prefix_replay(recomputed_prior_fills, on_disk_fills, fills_path)
    # ...same for signals.jsonl (using br.signals_generated / rebuild signal list) ...

    # -------- 12. Mutation: fingerprints -> fills -> signals -> state.json --------
    _append_new_fingerprints(state_dir, dataset, prior_forward_candle_count)
    for entry in new_entries: append_jsonl(fills_path, ...)
    for sig in new_signals: append_jsonl(signals_path, ...)
    save_state(state_dir, new_state)

    return PaperSessionResult(...)
```
