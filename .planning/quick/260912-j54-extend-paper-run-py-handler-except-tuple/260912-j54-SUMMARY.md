# Quick Task 260912-j54: Extend paper_run.py handler except-tuple Summary

Added `ProcessedPrefixMutatedError` to the `bt paper run` CLI handler's paper-session refusal `except (...)` tuple and to its `bithumb_bot.errors` import block, so a resumed paper session against a dataset whose already-processed forward prefix has been byte-mutated now exits cleanly with `bt paper run: refusal (ProcessedPrefixMutatedError): <message>` on stderr instead of surfacing as an uncaught exception. Added one new CLI adversarial test class proving the clean refusal, the absence of any traceback marker, and byte-identical on-disk audit-trail state (`state.json`, `candle_fingerprints.jsonl`, `fills.jsonl`, `signals.jsonl`) before and after the failed invocation.

## What Changed

**`src/bithumb_bot/cli/handlers/paper_run.py`:**
- Added `ProcessedPrefixMutatedError` to the `from bithumb_bot.errors import (...)` block (alphabetical placement between `PaperStateDirError` and `SidecarHashMismatchError`).
- Added `ProcessedPrefixMutatedError,` to the paper-session `except (...)` tuple wrapping the `run_paper_session(...)` call (alphabetical placement). No other line in the file changed — the shared refusal formatter `f"bt paper run: refusal ({type(exc).__name__}): {exc}"` already interpolates both the exception class name and the runner-provided message (which embeds the offending candle's `open_time_utc`).

**`tests/cli/test_handlers_paper_run.py`:**
- Added module-level helper `_write_dataset_with_mutated_last_high(tmp_path, *, name="dataset_mutated.json")` — a duplicate of the existing `_write_dataset` helper except the last forward candle's `high` is `"200000001"` instead of `"200000000"`. Written to a distinct dataset path (with its own sidecar) so the run-1 dataset's sidecar is untouched.
- Added new class `TestPaperRunProcessedPrefixMutationRefused` with one method, `test_mutated_forward_candle_on_resume_refuses_cleanly`, implementing the plan's 8-step assertion sequence:
  1. Golden-path run 1 (rc == 0), asserts `state.json` and a 2-line `candle_fingerprints.jsonl` exist.
  2. Snapshots pre-invocation bytes of `state.json`, `fills.jsonl`, `candle_fingerprints.jsonl`, and (conditionally) `signals.jsonl`.
  3. Builds the mutated dataset at a new path; second `--out` also points to a new path (`report2.json`) so the overwrite guard is never triggered.
  4. Asserts `rc2 == 1`.
  5. Asserts stderr contains `"ProcessedPrefixMutatedError"` and the offending candle's ISO-8601 `open_time_utc`.
  6. Asserts stderr contains no `"Traceback"` substring.
  7. Asserts `report2.json` and its sidecar were never created.
  8. Asserts all four audit-trail files are byte-identical to their pre-invocation snapshots.
